# 部署文档

## 环境要求

### 基础环境
| 软件 | 版本要求 | 说明 |
|------|---------|------|
| Node.js | >= 18.0.0 | 运行时环境 |
| pnpm | >= 8.0.0 | 包管理器 |
| PostgreSQL | >= 14.0 | 关系型数据库 |
| Redis | >= 7.0 | 缓存、队列 |
| FFmpeg | >= 5.0 | 音视频处理 |
| Docker | >= 24.0 | 容器化部署（可选） |

### 云资源要求
| 资源 | 最低配置 | 推荐配置 | 说明 |
|------|---------|---------|------|
| CPU | 4核 | 8核以上 | 视频渲染CPU密集型 |
| 内存 | 8G | 16G以上 | |
| GPU | 可选 | NVIDIA T4/V100 | 视频生成加速 |
| 存储 | 100G | 500G以上 | 存放素材和生成的视频 |
| 带宽 | 10M | 100M以上 | 媒体文件上传下载 |

## 本地开发部署

### 1. 克隆代码
```bash
git clone <仓库地址>
cd 2026-VidForge
```

### 2. 安装依赖
```bash
pnpm install
```

### 3. 配置环境变量
复制 `apps/backend/.env` 文件，修改为真实配置：
```env
# 服务配置
PORT=3001
NODE_ENV=development

# 数据库配置
DB_HOST=localhost
DB_PORT=5432
DB_USER=postgres
DB_PASSWORD=your_password
DB_NAME=vidforge

# Redis配置
REDIS_URL=redis://localhost:6379

# JWT配置
JWT_SECRET=your_jwt_secret_key
JWT_EXPIRES_IN=7d

# 火山引擎方舟 Ark 模型配置（必填 — 文本/视频生成依赖）
ARK_TEXT_PRIMARY_ENDPOINT_ID=ep-20260514115629-vhldw
ARK_TEXT_PRIMARY_API_KEY=ark-your-api-key
ARK_TEXT_PRIMARY_NAME=Doubao-Seed-2.0-pro
ARK_TEXT_PRIMARY_RATE_LIMIT=100RPM 50WTPM

ARK_VIDEO_PRIMARY_ENDPOINT_ID=ep-20260514120705-pqv86
ARK_VIDEO_PRIMARY_API_KEY=ark-your-api-key
ARK_VIDEO_PRIMARY_NAME=Doubao-Seedance-1.5-pro
ARK_VIDEO_PRIMARY_RATE_LIMIT=5并发

# OSS配置（可选，开发环境可先用本地存储）
OSS_ACCESS_KEY=your_oss_access_key
OSS_SECRET_KEY=your_oss_secret_key
OSS_BUCKET=vidforge-assets
OSS_ENDPOINT=oss-cn-beijing.aliyuncs.com
```

### 4. 初始化数据库
```bash
# 创建数据库
createdb vidforge

# 数据库表会自动同步（开发环境）
```

### 5. 启动服务
```bash
# 启动后端服务（端口3001）
pnpm --filter=@vidforge/backend start:dev

# 启动前端服务（端口3000）
pnpm --filter=@vidforge/frontend dev

# 或者同时启动
pnpm dev
```

### 6. 访问验证
- 前端页面：http://localhost:3000
- 后端API：http://localhost:3001/api
- Swagger文档：http://localhost:3001/api/docs

## Docker部署

### 1. 构建镜像
```bash
# 构建前端镜像
docker build -f apps/frontend/Dockerfile -t vidforge/frontend:latest .

# 构建后端镜像
docker build -f apps/backend/Dockerfile -t vidforge/backend:latest .
```

### 2. 使用docker-compose部署
```bash
# 启动所有服务
docker-compose up -d
```

docker-compose.yml示例：
```yaml
version: '3.8'
services:
  postgres:
    image: postgres:14
    restart: always
    environment:
      POSTGRES_DB: vidforge
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: your_password
    volumes:
      - postgres_data:/var/lib/postgresql/data
    ports:
      - "5432:5432"

  redis:
    image: redis:7
    restart: always
    volumes:
      - redis_data:/data
    ports:
      - "6379:6379"

  backend:
    image: vidforge/backend:latest
    restart: always
    ports:
      - "3001:3001"
    environment:
      DB_HOST: postgres
      REDIS_URL: redis://redis:6379
      # 其他环境变量...
    depends_on:
      - postgres
      - redis

  frontend:
    image: vidforge/frontend:latest
    restart: always
    ports:
      - "3000:80"
    depends_on:
      - backend

volumes:
  postgres_data:
  redis_data:
```

## 生产环境部署

### 1. 基础设施准备
- Kubernetes集群（1.24+）
- 托管PostgreSQL实例
- 托管Redis实例
- 对象存储服务（OSS/COS/S3等）
- GPU节点池（可选，用于视频生成加速）
- CDN加速服务

### 2. 配置CI/CD
使用GitHub Actions或GitLab CI实现自动化构建部署：
1. 代码提交触发构建
2. 自动化测试
3. 镜像构建并推送到镜像仓库
4. 滚动更新到Kubernetes集群

### 3. 环境变量配置
生产环境建议使用Kubernetes Secret或配置中心管理敏感配置：
- 数据库连接信息
- API密钥
- JWT密钥
- 云资源访问凭证

### 4. 可观测性配置
- **监控**：Prometheus + Grafana，监控QPS、延迟、错误率、队列长度等指标
- **日志**：ELK Stack，集中收集服务日志
- **链路追踪**：Jaeger，实现全链路请求追踪
- **告警**：配置异常告警规则，及时通知相关人员

## 性能优化建议

### 1. 视频渲染优化
- 使用GPU加速视频编码，提升渲染速度
- 渲染任务队列按优先级调度
- 热点素材缓存到本地，减少下载时间
- 支持任务并行处理，充分利用多核CPU/GPU

### 2. 存储优化
- 媒体文件使用对象存储，降低存储成本
- 开启CDN加速，提升用户访问速度
- 定期清理临时文件和过期素材
- 大文件分片上传，提升上传成功率

### 3. 接口优化
- 热点数据缓存到Redis，降低数据库压力
- 接口分页查询，避免大数据量返回
- 异步任务采用回调或轮询获取结果，避免长连接阻塞
- 开启Gzip压缩，减少传输数据量

## 常见问题

### 1. 视频生成速度慢
- 检查GPU是否正常工作，优先使用GPU加速
- 增加任务队列的Worker数量
- 优化FFmpeg参数，降低编码复杂度
- 升级服务器配置

### 2. 上传文件失败
- 检查Nginx/Ingress的上传大小限制
- 检查存储桶权限配置
- 大文件启用分片上传

### 3. 任务失败重试
- 查看任务错误信息，定位失败原因
- 检查依赖服务是否正常运行
- 增加重试次数，调整退避策略

### 4. 访问速度慢
- 开启CDN加速静态资源和媒体文件
- 优化前端资源打包，减少包大小
- 接口数据缓存，减少数据库查询
- 服务器部署到离用户近的区域
