# 系统架构说明

## 总体架构设计
采用分层前后端分离架构，各模块低耦合高内聚，支持水平扩展：

### 1. 接入层
- **前端**：React 18 + TypeScript + Vite 管理端，支持响应式布局适配PC/移动端
- **网关**：Node.js API网关，负责鉴权、流量控制、请求路由
- **CDN**：静态资源、媒体文件CDN加速

### 2. 业务服务层
- **素材管理服务**：负责素材上传、结构化处理、多维度检索、标签管理
- **剧本生成服务**：负责爆款分析、模板提炼、剧本智能生成、人工干预、分镜管理
- **视频创作服务**：负责智能剪辑、分镜渲染、预览导出、任务调度
- **Agent编排服务**：基于LangGraph实现AI工作流编排，支持多步骤任务调度
- **用户服务**：用户管理、权限控制、团队协作

### 3. AI能力层
- **火山引擎OpenAPI封装**：文生图、文生视频、图生视频、TTS、内容审核
- **开源模型适配**：支持Qwen/DeepSeek等开源大模型接入作为补充能力
- **向量检索**：基于Milvus实现素材Embedding相似度检索
- **Prompt管理**：模板管理、版本控制、A/B测试

### 4. 数据层
- **业务数据库**：PostgreSQL存储用户、素材、剧本、任务等结构化数据
- **缓存**：Redis实现任务进度、热点数据、Session缓存
- **对象存储**：OSS存储音视频素材、生成的视频文件
- **向量库**：Milvus存储素材特征向量
- **消息队列**：Kafka/RabbitMQ实现事件驱动、异步通知

### 5. 基础设施层
- **容器化部署**：基于Docker + Kubernetes，支持GPU资源弹性调度
- **CI/CD**：GitHub Actions实现代码提交自动构建、测试、部署
- **可观测性**：Prometheus监控、ELK日志、Jaeger全链路追踪
- **安全机制**：WAF防护、数据加密、合规审核

## 核心模块设计

### 素材模块
**核心流程**：上传 → 格式校验 → 结构化处理 → 标签提取 → 向量生成 → 存储
- 支持图片/视频/音频三类素材上传，自动校验格式与大小
- 视频/音频自动提取时长、帧率、码率等元数据
- 多模态理解自动生成标签、摘要、Embedding向量
- 支持关键词、标签、向量相似度多维度检索

### 剧本模块
**核心流程**：商品信息输入 → Prompt构建 → 大模型生成 → 分镜解析 → 存储
- 支持8种视频风格：写实、动画、极简、奢华、清新、动感、复古、科技
- 分镜包含画面描述、镜头运动、台词、时长、BGM、字幕完整信息
- 支持爆款仿写、模板生成、自动化生成多种生成模式
- 支持人工干预分镜内容，快速重新生成

### 创作模块
**核心流程**：任务创建 → 队列调度 → 素材生成 → 视频合成 → 导出存储
- 基于BullMQ实现异步任务队列，支持水平扩展
- FFmpeg实现音视频合成、转场、字幕、配音、BGM合成
- 支持多分辨率（720P/1080P/2K/4K）、多格式（MP4/MOV/AVI/WebM）、多比例（9:16/16:9/1:1）导出
- 实时进度推送，支持断点续传、失败重试

## 关键技术方案

### 任务调度方案
- 视频生成属于CPU/GPU密集型长耗时任务，采用异步队列处理
- 任务状态流转：PENDING → PROCESSING → GENERATING_ASSETS → RENDERING → SUCCESS/FAILED
- 支持优先级调度，支持任务取消、暂停、重试
- 失败任务自动重试2次，指数退避策略

### 安全合规方案
- 全链路内容审核：文本审核→图像审核→音频审核→视频审核
- 敏感内容自动识别，提前规避平台违规风险
- 自动生成AI内容标识，符合监管要求
- 素材版权校验，支持合规审核工作流

### 性能优化方案
- 热点素材、模板缓存到Redis，降低数据库压力
- 大文件分片上传、断点续传
- 视频渲染GPU池化，弹性调度
- 静态资源CDN加速，降低访问延迟

## 核心接口说明
| 模块 | 接口 | 说明 |
|------|------|------|
| 素材 | POST /api/material/upload | 上传素材 |
| 素材 | GET /api/material | 获取素材列表 |
| 剧本 | POST /api/script/generate | 生成剧本 |
| 剧本 | GET /api/script | 获取剧本列表 |
| 创作 | POST /api/creation/task | 创建视频任务 |
| 创作 | GET /api/creation/task/:id/progress | 查询任务进度 |
| 创作 | GET /api/creation/task | 获取任务列表 |

完整接口文档可查看Swagger：http://localhost:3001/api/docs
