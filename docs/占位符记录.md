## 2. 数据库 / Redis 配置

| 占位符名称 | 用途 | 默认行为 |
|-----------|------|---------|
| `DATABASE_URL` | PostgreSQL 连接串 | **必填**,启动失败 |
| `DB_SYNCHRONIZE` | TypeORM 自动建表 | dev=true / prod 默认 false,**首次部署需临时开 true** |
| `REDIS_URL` | BullMQ 持久化队列 | **可选**,缺失时降级进程内执行 |
| `JWT_SECRET` | JWT 签名密钥 | **必填**,建议 `crypto.randomBytes(64).hex` |
| `JWT_EXPIRES_IN` | Token 过期时长 | 默认 `7d` |

## 3. 部署相关

| 占位符名称 | 用途 | 说明 |
|-----------|------|------|
| `API_BASE_URL` | 后端公网 URL | 影响 `/static/...` 产物 URL 拼装 |
| `WEB_BASE_URL` | 前端公网 URL | 多个用 `,` 分隔,加入 CORS 白名单 |
| `PORT` | 后端监听端口 | Railway 自动注入,默认 3001 |
| `NODE_ENV` | 环境标识 | `production` 时启用 SSL |
| `VITE_API_BASE_URL` | 前端调后端 URL | 前端构建期注入 |
| `VITE_WS_URL` | WebSocket URL | 不填则同 API_BASE_URL |

## 4. 可选高级特性

| 占位符名称 | 用途 | 缺失时行为 |
|-----------|------|----------|
| `VOLC_TTS_APPID` + `VOLC_TTS_TOKEN` | 火山 OpenSpeech 语音合成 | 回落生成静音占位音频 |
| `VOLC_TTS_CLUSTER` | TTS 集群 | 默认 `volcano_tts` |
| `EMBEDDING_API_URL` | BGE-M3 向量服务 | 默认 `http://localhost:11434/api/embeddings`(Ollama),失败回落 LIKE 搜索 |
| `OSS_*` | 对象存储凭证(预留) | 当前未启用,产物落本地 `storage/outputs` |
