# 项目记忆文档
本文件记录项目开发过程中的关键信息、重要决策、用户明确的强约束，保证开发过程中记忆连贯。

## 项目核心信息
- 项目名称：电商场景AIGC带货视频生成系统
- 技术栈：React 18 + Node.js (NestJS) + TypeScript + 火山引擎OpenAPI
- 核心目标：实现商家端到端自动生成带货视频，支持素材管理、剧本生成、视频创作全流程
- 部署要求：前后端分离，容器化部署，支持GPU弹性调度

## 用户明确的强约束
1. 所有API Key、外部服务配置暂时使用占位符，待框架完成后统一填写
2. 每一轮会话最多处理2个任务节点，保证代码质量
3. 工程需集成ESLint、Prettier、Husky、StyleLint等代码规范工具
4. 代码分层合理，模块化清晰，对"素材-剧本-创作"三大模块做好抽象
5. 优先实现P0必做功能，再迭代P1、P2功能
6. 视频生成时长不超过15s
7. 支持9:16（竖版）和16:9（横版）两种画幅导出
8. 提交代码即触发CI/CD构建部署
9. 所有生成内容需要有合规审核机制
10. 优先使用火山引擎OpenAPI，可接入其他模型作为补充

## 重要技术决策
1. 采用pnpm monorepo管理前后端代码，工作区分为apps（前后端应用）和packages（公共包）
2. 前端使用Vite构建，Ant Design组件库
3. 后端使用NestJS框架，TypeORM作为ORM
4. 使用FFmpeg作为媒体处理核心工具
5. 使用LangGraph作为Agent编排框架
6. 使用Milvus作为向量数据库实现素材相似度检索
7. 任务队列使用BullMQ实现，支持长耗时任务调度
