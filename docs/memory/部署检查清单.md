# VidForge 部署检查清单

按照以下清单逐步完成部署，每完成一项打勾确认。

- [ ] 记录 AccessKeyID：`____________________`
- [ ] 记录 SecretAccessKey：`____________________`

- [ ] 创建存储桶，名称：`vidforge-assets`
- [ ] 设置权限：公共读、私有写
- [ ] 记录 Endpoint：`____________________`
- [ ] 记录 AccessKey：`____________________`
- [ ] 记录 SecretKey：`____________________`

## 第二阶段：后端部署（预计 45 分钟）

### 2.1 创建数据库
- [ ] 在 Railway 创建新项目
- [ ] 添加 PostgreSQL 服务
- [ ] 记录 DATABASE_URL：`____________________`

### 2.2 创建 Redis
- [ ] 在项目中添加 Redis 服务
- [ ] 记录 REDIS_URL：`____________________`

### 2.3 部署后端服务
- [ ] 添加 GitHub Repo 服务
- [ ] 选择仓库：`WANGLEVY9/VidForge`
- [ ] 设置 Root Directory：`apps/backend`
- [ ] 设置 Build Command：`npm install && npm run build`
- [ ] 设置 Start Command：`npm run start:prod`

### 2.4 配置环境变量
在 Railway 后端服务的 Variables 面板添加：

```env
# JWT 配置
JWT_SECRET=<运行生成命令获取>
JWT_EXPIRES_IN=7d

# 火山引擎
VOLC_ENGINE_ACCESS_KEY=<你的密钥>
VOLC_ENGINE_SECRET_KEY=<你的密钥>
VOLC_ENGINE_REGION=cn-beijing

# OSS
OSS_ACCESS_KEY=<你的密钥>
OSS_SECRET_KEY=<你的密钥>
OSS_BUCKET=vidforge-assets
OSS_ENDPOINT=<你的端点>

# 环境
NODE_ENV=production
```

- [ ] 生成 JWT_SECRET：
  ```bash
  node -e "console.log(require('crypto').randomBytes(64).toString('hex'))"
  ```
- [ ] 添加所有环境变量
- [ ] 记录后端服务 URL：`____________________`

### 2.5 验证后端部署
- [ ] 访问 `https://<后端URL>/api/health`
- [ ] 确认返回 `{"status":"ok",...}`
- [ ] 访问 `https://<后端URL>/api/docs` 查看 Swagger 文档

## 第三阶段：前端部署（预计 20 分钟）

### 3.1 导入项目到 Vercel
- [ ] 点击「Add New」→「Project」
- [ ] 选择 `WANGLEVY9/VidForge` 仓库
- [ ] Framework Preset：Vite
- [ ] Root Directory：`apps/frontend`
- [ ] Build Command：`npm run build`
- [ ] Output Directory：`apps/frontend/dist`

### 3.2 配置环境变量
- [ ] 添加 `VITE_API_BASE_URL` = `https://<后端URL>`

### 3.3 部署
- [ ] 点击「Deploy」
- [ ] 等待构建完成
- [ ] 记录前端 URL：`____________________`

### 3.4 更新后端 CORS
- [ ] 在 Railway 后端服务添加环境变量：
  ```env
  WEB_BASE_URL=https://<Vercel域名>
  ```
- [ ] 触发后端重新部署

## 第五阶段：域名配置（可选，预计 30 分钟）

### 5.1 购买域名
- [ ] 选择域名服务商（阿里云/腾讯云/Namecheap）
- [ ] 搜索并购买域名
- [ ] 记录域名：`____________________`

### 5.2 配置前端域名
- [ ] 在 Vercel 项目设置 → Domains 添加域名
- [ ] 添加 DNS 记录：
  ```
  类型: CNAME
  主机记录: www（或 @）
  记录值: cname.vercel-dns.com
  ```
- [ ] 等待 DNS 生效（最长 48 小时）

### 5.3 配置后端域名
- [ ] 在 Railway 服务设置 → Domains 添加域名
- [ ] 添加 DNS 记录：
  ```
  类型: CNAME
  主机记录: api
  记录值: <Railway提供的CNAME>
  ```
- [ ] 更新环境变量中的服务地址

## 常见问题快速排查

| 问题 | 检查项 |
|------|--------|
| 前端无法访问 | 检查 Vercel 部署状态、DNS 配置 |
| API 请求失败 | 检查后端服务状态、CORS 配置 |
| 数据库连接失败 | 检查 DATABASE_URL 格式、Railway 服务状态 |
| 文件上传失败 | 检查 OSS 配置、Bucket 权限 |
| 视频生成失败 | 检查火山引擎配置、API 配额 |
