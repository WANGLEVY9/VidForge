Agent State Graph (关键设计)

LangGraph 的核心是 StateGraph，每个节点是 Agent，边是状态转换：

StateGraph(AgentState)
  ├── Node: "orchestrator"      → 解析请求，规划任务
  ├── Node: "material_analysis" → 智能素材匹配 + 标签补充
  ├── Node: "script_generation" → 风格选择 + 分镜生成 + 文案
  ├── Node: "video_composition" → 拼接 + TTS + 字幕 + BGM
  ├── Node: "quality_control"   → 审核 + 评分 + 对比
  └── Edge: 顺序执行，每个节点读取/写入共享 AgentState

这个架构的评委亮点

  • 可视化 Graph: 答辩时可以展示 LangGraph Studio 或自定义的 Agent 流程图，直观看到每个节点的状态转换
  • State 可追溯: 每个 Agent 的输入/输出都记录在 AgentState 中，可以展示"AI 是如何一步步决策的"
  • 全栈 TypeScript: 前端 → 后端 → Agent 统一语言，架构整洁
  • 可中断/恢复: AgentState 可序列化，支持任务中断恢复
