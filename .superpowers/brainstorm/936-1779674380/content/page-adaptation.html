2. Material 素材库

┌──────────────────────┐ │ 🔍 搜索素材... 📷 │ ← 折叠式搜索栏 ├──────────────────────┤ │ [全部|图片|视频|音频] │ ← 横向滚动分类 ├──────────────────────┤ │ ┌───┐ ┌───┐ ┌───┐ │ ← 2列网格 │ │ │ │ │ │ │ │ │ │ 图 │ │ 图 │ │ 图 │ │ │ └───┘ └───┘ └───┘ │ │ 名称 │ 名称 │ 名称 │ │ ┌───┐ ┌───┐ ┌───┐ │ │ │ │ │ │ │ │ │ │ │ 图 │ │ 图 │ │ 图 │ │ │ └───┘ └───┘ └───┘ │ ├──────────────────────┤ │ 🏠 📁 📝 ▶ ⚙ │ └──────────────────────┘
  • 网格自适应：xs={12} (2列)，sm={8} (3列)
  • 触控操作：长按进入多选模式，左右滑动出现操作菜单
  • 搜索栏：默认收缩为图标，点击展开全宽输入框
  • 类型选择：顶部横向滚动 Segmented，可左右滑动切换

3. Script 剧本创作

  • 配置/结果切换：配置面板默认收起为"设置"按钮，结果区域占满全屏
  • 风格选择：2列网格 → 横向滚动图标（触碰更大面积）
