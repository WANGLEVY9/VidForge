Mobile Layout Architecture

A+C hybrid pattern — Bottom Tab Bar + FAB, with responsive shell structure.

1. 响应式断点

断点 布局 导航
< 768px 单列全屏 底部标签栏 + FAB
768px - 1024px 可折叠侧边栏 侧边栏 + 顶部栏
> 1024px 侧边栏+内容区 完整侧边栏

2. Shell 结构

<MobileShell>                    // 响应式外壳
  ├── <TopBar>                    // 顶部栏（搜索+通知+用户）
  │     ├── SearchInput
  │     ├── NotificationBadge
  │     └── UserAvatar
  │
  ├── <SwipeableView>             // 左右滑动切换页面
  │     ├── DashboardPage
  │     ├── MaterialPage
  │     ├── ScriptPage
  │     ├── CreationPage
  │     └── AbComparePage
  │
  ├── <BottomTabBar>              // 玻璃拟态底部标签
  │     ├── TabItem (工作台)       // 带活跃态指示器
  │     ├── TabItem (素材库)
  │     ├── TabItem (剧本)
  │     ├── TabItem (创作)
  │     └── TabItem (AB对比)
  │
  └── <FabButton>                 // 浮动快速创作按钮
        └── QuickActionMenu       // 展开：快速创作 / 上传素材

3. 底部标签栏交互

  • 玻璃拟态风格：backdrop-filter: blur(20px)，半透明背景，与现有暗色主题统一
  • 自动隐藏：向下滚动时收起（+transform: translateY(100%)），向上滚动或到达顶部时显示
  • 活跃态指示器：底部发光的渐变线条 + 图标微动效（选中态放大 1.1x）
  • Badge 通知：素材审核、导出完成等系统通知以红点显示

4. FAB 快速创作

  • 位置：悬浮在底部标签栏上方 16px，偏右
  • 交互：点击展开扇形菜单（快速创作 / 上传素材），点击空白处关闭
  • 动效：展开/收起带弹簧弹性动画（spring 动画）
  • 上下文感知：在视频播放/全屏模式下自动隐藏
