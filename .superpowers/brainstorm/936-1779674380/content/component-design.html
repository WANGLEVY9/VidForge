Mobile Component Design

Props, state, and behavior for the 4 core mobile components.

1. MobileShell — 响应式外壳

// 核心逻辑：监听视口宽度，切换布局模式 interface MobileShellProps { children: ReactNode; sidebar: ReactNode; // 桌面侧边栏 tabBar: ReactNode; // 移动底部标签 topBar: ReactNode; // 移动顶部栏 fab?: ReactNode; // 可选 FAB }
宽度 渲染内容
< 768px TopBar + children + TabBar + FAB
768-1024px sidebar(collapsible) + TopBar + children
> 1024px sidebar(expanded) + children

实现方案：CSS @container query + React context 提供断点状态。使用 matchMedia 监听避免 ResizeObserver 开销。

2. BottomTabBar — 玻璃拟态标签栏

interface TabConfig { key: string; // 'dashboard' | 'material' | 'script' | 'creation' | 'ab-compare' label: string; // 显示文字 icon: ReactNode; // 图标组件 badge?: number; // 通知数(0=不显示) href: string; // 路由路径 } interface BottomTabBarProps { tabs: TabConfig[]; activeKey: string; onChange: (key: string) => void; visible: boolean; // auto-hide 控制 }
特性 行为
样式 backdrop-filter: blur(20px)，背景色 rgba(15,15,26,0.85)，上边框 1px solid rgba(255,255,255,0.06)
活跃态 图标放大 1.1x + 底部发光渐变线 (indigo→purple) + 颜色过渡
Auto-hide 监听 scroll 方向：向下滚动时 transform: translateY(100%)，向上或到顶时恢复
安全区 padding-bottom: env(safe-area-inset-bottom) 适配刘海屏

3. FabButton — 浮动快速创作

interface FabAction { key: string; label: string; icon: ReactNode; onClick: () => void; } interface FabButtonProps { actions: FabAction[]; // 最多4个 hidden?: boolean; // 全屏/播放时隐藏 } // 内部状态 interface FabState { open: boolean; // 菜单展开状态 animating: boolean; // 弹簧动画中 }

位置：固定定位 bottom: calc(64px + env(safe-area-inset-bottom))（标签栏上方），right: 16px

尺寸：主按钮 56×56px，子菜单按钮 44×44px

动画：展开时子按钮从主按钮位置扇形弹出 (transform: translate() + scale(0→1))，带 0.4s spring easing

状态：点击主按钮切换 open/close，点击空白处或切换路由时自动关闭

4. SwipeableView — 页面滑动手势

interface SwipeableViewProps { pages: { key: string; content: ReactNode }[]; activeKey: string; onChange: (key: string) => void; threshold?: number; // 滑动触发阈值 px，默认 60 transition?: string; // CSS transition，默认 'transform 0.3s cubic-bezier(0.4, 0, 0.2, 1)' } // 内部状态 interface SwipeState { isDragging: boolean; startX: number; currentX: number; direction: 'left' | 'right' | null; }

手势识别：

  • onTouchStart → 记录起始 X 坐标
  • onTouchMove → 计算偏移量，实时 translate 页面（回弹跟随）
  • onTouchEnd → 判断是否超过阈值，是则切换到相邻页面，否则回弹动画复位
  • 防止误触：垂直滑动 > 水平滑动时不触发（判断 angle）

高性能：使用 transform: translate3d() + will-change: transform 启动 GPU 合成层，避免布局抖动。
