Mobile Navigation Pattern

How should the sidebar transform on mobile devices? Choose the pattern that best fits our creative studio brand.

A

Bottom Tab Bar

│ 🏠  📁  📝  ▶  ⚙ │

Standard mobile pattern, 5 tabs. Familiar to users. Each tab shows a badge for notifications.

Hamburger menu opens overlay sidebar. More screen space for content. Closer to desktop experience.

C

FAB + Quick Switch

┌──────────────────┐
│                  │
│   Content Area   │
│                  │
│                  │
│         [+] FAB  │
│  ←  →  dots     │
└──────────────────┘

FAB → Quick Actions
    ├ 快速创作
    └ 上传素材

Swipe left/right to switch
between recent pages

Creative, unique approach. Floating action button for primary actions, swipe to switch pages. Less conventional but more immersive.

Considerations:

  • Bottom Tab: Standard, predictable, but takes up screen real estate
  • Collapsible: Full content area, but hamburger menus have lower engagement
  • FAB + Swipe: Unique and immersive, but less discoverable
