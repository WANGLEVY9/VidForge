Responsive CSS Strategy

Extend existing dark-theme tokens for mobile, container queries, touch adaptations.

1. Token Extensions — tokens.css

/* Mobile-specific tokens */ :root { /* Safe areas */ --safe-area-top: env(safe-area-inset-top, 0px); --safe-area-bottom: env(safe-area-inset-bottom, 0px); --safe-area-left: env(safe-area-inset-left, 0px); --safe-area-right: env(safe-area-inset-right, 0px); /* Shell dimensions */ --top-bar-height: 48px; --tab-bar-height: 56px; --tab-bar-height-total: calc(56px + var(--safe-area-bottom)); --fab-size: 56px; --fab-bottom: calc(var(--tab-bar-height) + 16px); /* Breakpoints (for reference in JS) */ /* --bp-mobile: 768px; */ /* --bp-tablet: 1024px; */ /* Touch */ --touch-target-min: 44px; /* Apple HIG minimum */ }

2. Container Queries — responsive.css (new)

/* Page container for CQ */ .page-container { container-type: inline-size; container-name: page; } /* Show/hide sidebar vs tab bar */ @container page (width < 768px) { .desktop-sidebar { display: none; } .mobile-tab-bar { display: flex; } .page-content { padding-bottom: var(--tab-bar-height-total); } } @container page (width >= 768px) { .desktop-sidebar { display: flex; } .mobile-tab-bar { display: none; } .page-content { padding-bottom: 0; } } /* Mobile 2-column grid auto-switch */ @container page (width < 480px) { .material-grid { grid-template-columns: repeat(2, 1fr); } }

3. Touch vs Pointer Adaptations

CSS Rule 效果
@media (hover: hover) and (pointer: fine) 桌面悬停效果（hover-lift, card:hover）仅在支持悬停的设备启用
@media (hover: none) and (pointer: coarse) 触控设备：增大点击区域 min-height: var(--touch-target-min)
@media (prefers-reduced-motion) 减弱动效：减少 transition/animation 复杂度
-webkit-tap-highlight-color: transparent 去除移动端默认触摸高亮
