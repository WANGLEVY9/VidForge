# 电商场景AIGC带货视频生成系统实现规划

## 一、项目概述
### Summary
本项目是面向TikTok Shop等跨境电商商家的AIGC带货视频生成全链路系统，基于React、Node.js、TypeScript技术栈，对接火山引擎OpenAPI与开源大模型能力，实现素材管理、剧本智能生成、视频一键创作全流程自动化，支持商家快速生成符合平台规则、高转化潜力的带货短视频，同时满足工程架构规范、功能分级要求与可观测性标准。

### Current State Analysis
当前为全新项目启动阶段，无现有代码资产，需从零搭建前后端分离架构，实现「素材-剧本-创作」三大核心模块，优先完成P0必做功能，逐步迭代P1进阶与P2加分功能，最终交付符合赛题要求的全栈可运行系统与完整项目材料。

---

## 二、总体架构设计（符合业界云原生标准）
采用分层前后端分离架构，各模块低耦合高内聚，支持水平扩展：
1. **接入层**：
   - 前端：React 18 + TypeScript + Ant Design 管理端，支持响应式布局适配PC/移动端
   - 网关：Node.js API网关，负责鉴权、流量控制、请求路由
2. **业务服务层**：
   - 素材管理服务：负责素材上传、结构化处理、多维度检索
   - 剧本生成服务：负责爆款分析、模板提炼、剧本智能生成与人工干预
   - 视频创作服务：负责智能剪辑、分镜渲染、预览导出
   - Agent编排服务：基于LangGraph实现AI工作流编排，支持多步骤任务调度
3. **AI能力层**：
   - 统一封装火山引擎OpenAPI：文生图、文生视频、图生视频、TTS、内容审核
   - 开源模型适配：支持Qwen/DeepSeek等开源大模型接入作为补充能力
   - 向量检索：基于Milvus实现素材Embedding相似度检索
4. **数据层**：
   - 业务数据库：PostgreSQL存储用户、素材、剧本、任务等结构化数据
   - 缓存：Redis实现任务进度、热点数据缓存
   - 对象存储：OSS存储音视频素材、生成的视频文件
   - 向量库：Milvus存储素材特征向量
5. **基础设施层**：
   - 基于Docker容器化部署，支持GPU资源弹性调度
   - 集成CI/CD流程，提交代码自动触发构建部署
   - 接入日志、监控、全链路追踪能力

## 三、核心功能模块实现规划
### （一）P0 必做功能（优先实现）
| 功能点 | 实现方案 | 涉及文件 |
|--------|----------|----------|
| 商品素材上传 | 支持拖拽上传商品主图、视频、参考素材，自动校验格式与大小 | 前端：`src/pages/material/upload.tsx` <br> 后端：`src/server/modules/material/upload.controller.ts` |
| 剧本生成 | 输入商品信息（标题、卖点、目标人群），自动生成包含分镜、台词、BGM的完整剧本 | 前端：`src/pages/script/generate.tsx` <br> 后端：`src/server/modules/script/generate.service.ts` |
| 基础分镜 | 生成默认分镜列表，展示每个分镜的画面描述、时长、台词 | 前端：`src/components/Storyboard/List.tsx` <br> 后端：`src/server/modules/script/storyboard.service.ts` |
| 一键成片 | 基于素材与剧本自动完成视频拼接、配音、字幕合成，生成15s以内短视频 | 后端：`src/server/modules/creation/render.service.ts` <br> 依赖：FFmpeg媒体处理库 |
| 任务进度 | 实时展示视频生成进度，支持任务状态查询 | 前端：`src/components/Task/Progress.tsx` <br> 后端：`src/server/modules/task/progress.service.ts` |
| 预览导出 | 在线预览生成的视频，支持导出9:16/16:9等多分辨率格式 | 前端：`src/pages/creation/preview.tsx` <br> 后端：`src/server/modules/creation/export.service.ts` |

### （二）P1 进阶功能
| 功能点 | 实现方案 |
|--------|----------|
| 素材标签/Embedding检索 | 对素材进行多模态理解，提取标签与特征向量，支持关键词、标签、向量相似度检索 |
| 智能剪辑Agent | 基于LangGraph编排剪辑工作流，自动完成素材匹配、转场、字幕、配音合成 |
| 分镜级编辑 | 支持拖拽调整分镜顺序、修改分镜内容、替换素材、调整时长，修改后局部重渲染 |
| TTS/字幕/BGM | 对接火山引擎TTS生成多语种配音，自动生成字幕，匹配合规BGM |
| 失败重试 | 任务失败自动重试，支持断点续传，展示清晰的失败原因与解决方案 |
| 生成过程trace | 全链路追踪生成任务的每一步状态、耗时、调用日志，便于排查问题 |
| Mock数据看板 | 模拟展示生成因子与转化效果的关联分析，支持数据可视化 |

### （三）P2 加分功能
| 功能点 | 实现方案 |
|--------|----------|
| 多因子归因 | 分析剧本因子、素材特征与视频转化效果的关联关系，沉淀最优创作规则 |
| Agent编排 | 基于LangGraph实现复杂工作流编排，支持多AI能力协同完成视频生成 |
| A/B对比 | 同时生成多版本视频，支持效果对比与自动择优 |
| CI/CD | 集成GitHub Actions实现代码提交自动构建、测试、部署 |
| 可观测性 | 接入Prometheus监控、ELK日志、Jaeger全链路追踪 |
| 长任务体验 | 优化长耗时任务的进度展示、失败兜底、通知机制 |
| 合规审核流 | 内置文本、图像、音频、视频多层审核机制，对接内容审核API |

## 四、技术选型与决策
### Assumptions & Decisions
1. **前端技术栈**：选定React 18 + TypeScript + Ant Design + Vite，生态成熟，适合中后台系统快速开发，满足响应式布局需求
2. **后端技术栈**：选定Node.js + NestJS + TypeScript作为主后端框架，IO性能优异适合媒体处理调度；LangGraph作为Agent编排框架，支持复杂工作流实现
3. **AI能力**：默认对接火山引擎OpenAPI实现文生图、文生视频、TTS、审核能力，支持开源模型接入作为补充
4. **媒体处理**：选定FFmpeg作为音视频处理核心工具，业界标准支持几乎所有格式操作
5. **存储方案**：PostgreSQL存业务数据，Redis做缓存，OSS存媒体文件，Milvus做向量检索
6. **工程规范**：集成ESLint、Prettier、Husky、StyleLint保证代码质量，采用monorepo单仓库管理前后端代码

## 五、实现路径与验证标准
### 实现阶段
1. **第一阶段：工程基建搭建**
   - 完成项目初始化、代码规范配置、前后端基础架构搭建
   - 验证：可正常启动前后端服务，代码规范校验生效
2. **第二阶段：P0功能实现**
   - 完成素材上传、剧本生成、基础分镜、一键成片、任务进度、预览导出核心功能
   - 验证：端到端可运行，上传商品素材后可生成完整视频并导出
3. **第三阶段：P1功能迭代**
   - 完成素材检索、分镜编辑、TTS/字幕/BGM、任务重试、数据看板等进阶功能
   - 验证：支持分镜级干预，视频生成成功率>90%
4. **第四阶段：P2功能优化**
   - 完成Agent编排、A/B测试、CI/CD、可观测性、合规审核等加分功能
   - 验证：系统稳定性高，可支持多用户并发使用
5. **第五阶段：项目交付准备**
   - 完成README、架构文档、演示视频、Demo部署等交付材料
   - 验证：符合赛题要求的所有交付字段标准

### Verification Steps
1. **功能验证**：
   - P0验证：上传1个商品素材，生成剧本，点击一键成片，可正常生成视频并下载
   - P1验证：可通过关键词检索素材，可修改分镜内容并重新生成视频
   - P2验证：可同时生成多版本视频进行A/B对比，任务失败可自动重试
2. **工程验证**：
   - 代码符合规范，无ESLint错误
   - 前后端接口文档完整，可通过Swagger查看
   - Docker镜像构建成功，可一键部署
3. **体验验证**：
   - 页面首屏加载时间<2s
   - 视频生成进度实时展示，无明显卡顿
   - 移动端访问适配正常
